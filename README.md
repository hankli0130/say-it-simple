# Say It Simple

學習北美職場英文

## 我的常用情境

- 用美式職場英文向老闆、投資人和同事溝通
  - 每天、每週回報專案進度
  - 報告新版本發布的內容

## 執行計畫

1. **我寫英文報告。** 進度報告放在 `samples/progress/`，版本發布報告放在 `samples/releases/`。寫完後，把檔案路徑給 AI Agent，說明要給誰看、希望對方知道什麼。
2. **AI Agent 在對話中 review，我自己修改。** AI Agent 指出需要調整的原句，說明原因，必要時提供英文改寫範例。Review 意見和改寫範例只留在對話中，由我決定怎麼修改報告。
3. **AI Agent 把口說練習和會議追問寫進檔案。** 我確認報告內容後，AI Agent 依據定稿，在我寫的同一份報告末尾加上「口說練習」和「會議追問」兩節，寫入一段約 30 秒的英文口說稿、三到四個提示關鍵字，以及一題聽眾可能提出的英文追問和參考回答。

每次用報告末尾的練習內容練 5 分鐘。目標是在每週視訊會議上，只看關鍵字就能講清楚進度或發布重點，並回答一題追問。

### 每天 5 分鐘口說練習

第一天先用這段 [8/20 週報](samples/progress/2026-08-20-weekly-progress-report.md) 的口說版暖身。

> This week, I finished setting up CI for root-android.  
> I also fixed an issue with the OTP service.  
> On the broadcast side, I added support for 23 languages.  
> Right now, I’m setting up CI for root-rust.

1. **照念兩遍。** 每行講完停一下。先練熟三個開頭：*This week, I finished …*、*I also fixed …*、*Right now, I’m …*。
2. **遮住原文講一遍。** 只看提示：Android CI → OTP fix → 23 languages → Rust CI。用自己的話串起來。
3. **換成今天的工作。** 從當天日報挑兩件事，用 *I finished …* 講一件已完成的事，再用 *Right now, I’m …* 講手上的工作。
4. **回答一題追問。** 先念問題 *What’s left to do?*，再接 *I still need to finish setting up CI for root-rust.* 每天把回答換成自己真正的下一步。

### 視訊會議當天

從本週日報挑出想讓聽眾記住的進展，寫下三、四個英文關鍵字。開會前只看關鍵字講一次，計時約 30 秒，再練一題對方可能會問的問題。
